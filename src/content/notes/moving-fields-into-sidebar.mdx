---
title: "Moving Fields into the node edit sidebar"
description: "How to move fields into the node edit sidebar in Drupal 8+."
published: 2025-05-27
---

```php
function theme_name_form_node_form_alter(&$form, FormStateInterface $form_state, $form_id)
{
  // Adding a section to the node form where odd settings can be pushed.
  $form['editoradvanced'] = [
    '#type' => 'details',
    '#title' => t('Tab name'),
    '#open' => TRUE,
    '#group' => 'advanced',
    '#weight' => -10,
    '#access' => TRUE,
    '#optional' => TRUE,
  ];
  $form['field_name']['#group'] = 'editoradvanced';
}
```
