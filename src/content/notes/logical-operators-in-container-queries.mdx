---
title: Logical Operators in Container Queries
description: "Using logical operators in container queries to create responsive designs."
published: 2025-05-27
---

```css
.container {
  container-type: inline-size;
}
.item {
  background: #ffcc00;
  @container ((width > 220px) and (width < 388px)) or (width > 580px) {
    background: #ee9b00;
  }
  /* equivalent to *
	@container (width > 220px) and (width < 388px) {
		background: #ee9b00
	}
	
	@container (width > 580px) {
		background: #ee9b00
	}*/
}
```
