---
title: "Building image with URI in Twig"
description: "How to build an image with a URI in Twig for Drupal."
published: 2025-05-27
---

```php
set image = {
  '#theme': 'image_style',
  '#style_name': 'featured',
  '#uri': paragraph.field_item_image.entity.field_media_image.entity.fileuri,
  '#alt': paragraph.field_item_image.entity.field_media_image[0].alt,
  '#attributes': { class: 'yourclass' },
}
```
